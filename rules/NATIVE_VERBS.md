# Native Verbs for Natural English

This guide contains practical rules for using verbs that native speakers naturally use in everyday English. These are NOT grammar rules—they are functional usage guidelines.

## Rules 100-186: Verbs Native Speakers Use

### 100. Use "fix" instead of "resolve" in casual contexts

**Correct Examples:**
- Can you fix the printer?
- I'll fix it tomorrow.
- Can you fix this for me?
- Let's fix it right now.
- We'll fix it later.

**Incorrect Examples:**
- Can you resolve the printer? ❌
- I will resolve it tomorrow. ❌
- Can you resolve this for me? ❌
- Let us resolve it right now. ❌
- We will resolve it later. ❌

---

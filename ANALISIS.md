# Análisis Funcional: Camino Idiomático - English for Tech Professionals

## 1. Propuesta de Valor

Webapp para entrenar a ingenieros de TI a hablar inglés técnico con clientes en USA y/n瑟ure empresas de USA.

### Problema que resuelve

- Ingenieros con buen nivel técnico pero no pueden expresarse en inglés
- Miedo a llamadas con clientes gringos
- Entrevistas técnicas fallan por falta de comunicación
- No know how de cultura corporativa americana

### Solución

Practicar escenarios reales de trabajo tech con retroalimentación instantánea.

## 3. Propuesta Pedagógica

### Enfoque: Inglés Técnico + Cultura Corporate

| Inglês General | Camino Idiomático - TI |
|----------------|------------------------|
| "How are you?" | "What's your stack?" |
| "I like coffee" | "I've been working with AWS" |
| Conversación social | Reuniones técnicas |
| Gramática básica | Technical storytelling |
| Películas generales | Tech talks, podcasts de devs |

### Por qué funciona

- **Contexto已知**: El ingeniero ya sabe el contenido técnico en español
- **Aplicación inmediata**: Lo que practica, lo usa en el trabajo
- **Culturareal**: USA corporate norms (small talk, git defaults to master, standups en inglés)

## 4. Flujo de Usuario

### 4.1 Test Inicial (3 min)

```
Pregunta 1: ¿cuál es tu rol? (select)
Pregunta 2: Describe tu proyecto actual (type - 2 sentences)
Pregunta 3: Listen and repeat: "I've been working on..." 
Pregunta 4: Why do you want to work in USA? (type - 3 sentences)
Output: Nivel estimado + área prioritaria
```

### 4.2 Sesión Diaria (15 min)

```
Elegir área → hacer ejercicio → feedback → siguiente → completar → streak
```

**Áreas específicas TI:**
- 📞 **Calls** - Llamadas con clientes
- 🎤 **Interviews** - Entrevistas técnicas
- 🗣️ **Meetings** - Reuniones de equipo
- 📊 **Presentations** - Presentaciones técnicas

## 5. Features Clave

### 5.1 Calls con Clientes

**Escenarios:**

| Escenario | Contexto | Diálogo |
|-----------|----------|---------|
| 1 | Llamada inicial con cliente | "Hi, this is [name] from [company]. We're seeing an issue..." |
| 2 | Technical troubleshooting | "Can you walk me through the error?" |
| 3 | Status update | "Just wanted to give you a quick update on the project..." |
| 4 | Escalation | "I need to bring this to the senior team..." |
| 5 | Demo call | "Here's what we built for you..." |

**Estructura del ejercicio:**
```
Ver contexto: "Client is complaining about API latency"
→ Ver diálogo modelo (audio + texto)
→ Elegir respuesta (3 opciones, una es correcta)
→ Ver resultado + Audio nativo
→ Repetir en voz alta
→ Feedback
→ Siguiente
```

### 5.2 Entrevistas Técnicas

**Fases de entrevista:**

| Fase | Duración | Qué prácticos |
|------|----------|----------------|
| Intro | 2 min | Self-introduction + "Tell me about yourself" |
| Technical | 15 min | Explicar proyectos, resolver problema |
| Behavioral | 5 min | "Tell me about a time you..." |
| Questions | 3 min | "Do you have questions for me?" |

**Ejercicios:**

1. **Self-Introduction (30-60 seg)**
   - Modelo: "I'm a backend developer with 3 years of experience..."
   - Grabar tu versión
   - Feedback

2. **Explain a Project (2 min)**
   - "Walk me through a project you've worked on..."
   - Estructura: Problem → Solution → Result
   - Grabar + feedback

3. **Technical Problem**
   - "How would you scale a system to 10M users?"
   -Pensar en voz alta (think aloud)
   - Feedback en estructura y vocabulario

4. **Behavioral Questions**
   - "Tell me about a time you failed"
   - "Tell me about a time you had a conflict with a teammate"
   - STAR method practice

5. **Questions for Interviewer**
   - "¿Qué preguntar cuando te dicen 'do you have questions?'"
   - Lista de preguntas inteligentes

### 5.3 Reuniones de Equipo

**Escenarios:**

| Escenario | Contexto |
|-----------|----------|
| Daily standup | "What did you do yesterday? What will you do today?" |
| Sprint planning | "I estimate this will take about 2 days" |
| Code review | "I'm concerned about this approach because..." |
| Bug triage | "This is a critical issue, we need to prioritize" |
| Retro | "What went well? What could we improve?" |

### 5.4 Presentations

**Formatos:**

- Demo de producto (5 min)
- Architectural overview (10 min)
- Post-mortem de incidente (5 min)

## 7. Cultura Corporativa USA

### 7.1 Small Talk

**Temas apropiados:**
- Weather (siempre seguro)
- Sports locales (NBA, NFL)
- Weekend plans
- Coffee/food preferences

**Temas a evitar:**
- Política
- Religión
- Salario
- Edad

**Frases útiles:**
- "How's your morning going?"
- "Any exciting weekend plans?"
- "Did you catch the game last night?"
- "I'm still adjusting to the coffee here" (chiste común)

### 7.2 Email Etiquette

| Situación | Frase |
|-----------|-------|
| Pedir algo | "Would you mind..." |
| Pedir ayuda | "Could you help me with..." |
| Disculpa | "I apologize for the delay..." |
| Agradecer | "I really appreciate..." |
| Cerrar | "Best regards," "Cheers," |

### 7.3 Reuniones

**Normas:**
- Ser puntual (early = on time, on time = late)
- Camera encendida es preferred
- Speak up si tienes algo que decir
- "Do you have any questions?" siempre al final
- Es normal interrumpir con "Sorry, can I add something?"

### 7.4 Entrevistas - Lo que buscan

**Hard skills:**
- Capacidad técnica
- Conocimiento de herramientas
- Capacidad de aprendizaje

**Soft skills:**
- Comunicación clara
- Colaboración
- Adaptabilidad
- Iniciativa

**red flags:**
- No hacer preguntas
- No saber explicar proyectos
- Ser demasiado pasivo
- No tener preguntas para el interviewer

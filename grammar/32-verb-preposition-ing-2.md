# Verb + Preposition + -ing: There's No Point in -ing, It's Worth -ing - Grammar Guide

## Introduction

Additional structures for expressing futility and value.

---

## There's No Point in -ing

### Use: Stating Futility

> "There's **no point in upgrading** obsolete hardware."
> "There's **no point in maintaining** the old system."

### Structure

**There's no point in + verb-ing**

> ✅ "There's no point in **waiting** for the update."

---

## It's Worth -ing

### Use: Indicating Benefit

> "It's **worth learning** new programming languages."
> "It's **worth exploring** cloud technologies."

### Structure

**It's worth + verb-ing**

> ✅ "It's worth **investing** in security training."

---

## Summary of All Forms

| Expression | Use | Example |
|------------|-----|---------|
| **Succeed in -ing** | Achievement | "We succeeded in launching..." |
| **Insist on -ing** | Determination | "We insist on testing..." |
| **There's no point in -ing** | Uselessness | "There's no point in doing..." |
| **It's worth -ing** | Value | "It's worth doing..." |

---

## Uses in IT

### There's No Point in -ing
> "There's **no point in coding** in an outdated language."
> "There's **no point in supporting** that version."
> "There's **no point in using** manual methods."

### It's Worth -ing
> "It's **worth attending** the conference."
> "It's **worth noting** the improvements."
> "It's **worth considering** the new approach."

## Practice Exercises

### Complete the sentences:

1. There's no point ___(upgrade) the old server. → **in upgrading**
2. It's worth ___(explore) the new cloud options. → **exploring**
3. There's no point ___(maintain) that system. → **in maintaining**
4. It's worth ___(invest) in training. → **investing**
5. There's no point ___(wait) for approval. → **in waiting**

## Quick Summary

| Structure | Meaning | Example |
|-----------|---------|---------|
| **no point in -ing** | Useless | "No point in doing it" |
| **worth -ing** | Beneficial | "Worth doing it" |

# Irregular Verbs in IT - Grammar Guide

## Introduction

Irregular verbs don't follow standard patterns. Essential for IT documentation and reports.

---

## Common Irregular Verbs

| Base | Past | Past Participle | Use |
|------|------|---------------|-----|
| **write** | wrote | written | "I wrote the report." |
| **break** | broke | broken | "The server broke." |
| **choose** | chose | chosen | "We chose Python." |
| **drive** | drove | driven | "She drives the project." |
| **speak** | spoke | spoken | "He spoke at the meeting." |
| **begin** | began | begun | "We began testing." |
| **bring** | brought | brought | "It brought results." |
| **build** | built | built | "They built the system." |

---

## IT Context Examples

### Write - Wrote - Written
> "I **wrote** a Python script."
> "The code was **written** last week."
> "She has **written** the documentation."

### Break - Broke - Broken
> "The server **broke** during the update."
> "The network **broke** down."
> "It has **broken** twice this month."

### Choose - Chose - Chosen
> "We **chose** the cloud solution."
> "The option **chosen** was best."
> "He has **chosen** to lead the team."

## Practice Exercises

### Complete:

1. I ___ the report yesterday. (write) → **wrote**
2. The server ___. (break) → **broke**
3. We ___ Python. (choose) → **chose**
4. She ___ to the team. (speak) → **spoke**
5. The system has ___ twice. (break) → **broken**

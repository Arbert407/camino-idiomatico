# Superlatives and Word Order - Grammar Guide

## Introduction

Superlatives express the highest degree; word order structures sentences.

---

## Superlatives

### Short Adjectives (+ -est)

| Base | Superlative |
|------|------------|
| fast | fastest |
| cheap | cheapest |
| old | oldest |
| new | newest |

### Long Adjectives (most + adjective)

| Base | Superlative |
|------|------------|
| efficient | most efficient |
| reliable | most reliable |
| secure | most secure |
| user-friendly | most user-friendly |

---

## Using The

> "This is **the fastest** processor we have."
> "She is **the most skilled** coder on the team."

---

## Word Order

### Standard Order: S-V-O-T

| Subject | Verb | Object | Time |
|---------|------|-------|------|
| The server | crashed | yesterday | |

### Time First (Emphasis)

| Time | Subject | Verb | Object |
|------|---------|------|-------|
| Yesterday, | the server | crashed | |

> "**Yesterday**, the server crashed."
> "**Yesterday** the server crashed." (no comma)

---

## Uses in IT

### Superlatives
> "This is **the most secure** method."
> "It's **the fastest** solution available."
> "She is **the most skilled** developer."

### Word Order
> "The server **crashed yesterday**."
> "**Yesterday**, we identified the issue."
> "The system **failed during the update**."

---

## Practice Exercises

### Complete the sentences:

1. It's ___ processor we have. (fast) → **the fastest**
2. She's ___ coder on the team. (skilled) → **the most skilled**
3. This is ___ method available. (secure) → **the most secure**
4. The server crashed ___. (yesterday) → **yesterday**
5. ___ the server crashed. (yesterday) → **Yesterday**

---

## Common Mistakes

### ❌ "most fastest" (double)
> ✅ "**the fastest**"

### ❌ Missing article
> ✅ "**the** fastest" not "fastest"

---

## Quick Summary

| Form | Structure | Example |
|------|-----------|---------|
| Short | -est | fastest |
| Long | most + adjective | most efficient |
| Word Order | S-V-O-Time | server crashed yesterday |

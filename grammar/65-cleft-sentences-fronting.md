# Cleft Sentences and Fronting in IT - Grammar Guide

## Cleft Sentences

### Purpose: Emphasis

**Structure:** It + be + emphasis + that/who + rest

> "**It was the power failure** that caused the crash."
> "**It is the security** that needs improvement."

---

## Fronting

### Purpose: Move information forward

**Structure:** Move modifier to beginning

> "Due to the bug, the system failed."
> "Because of the error, we lost data."

---

## Types of Cleft Sentences

| Type | Example |
|------|----------|
| **It + be** | "**It was the outdated code** that caused the breach." |
| **It + be + not** | "**It wasn't the hardware** that failed." |
| **What** | "**What we need** is more training." |
| **All + what** | "**All what we did** was restart." |

---

## Fronting in IT

| Type | Example |
|------|----------|
| **Due to** | "**Due to the bug**, the system crashed." |
| **Because of** | "**Because of the update**, we lost data." |
| **With** | "**With the new configuration**, performance improved." |

---

## Uses in IT

### Cleft Sentences
> "**It was the security patch** that fixed the vulnerability."
> "**It is the processing speed** that needs improvement."
> "**What we need** is more bandwidth."

### Fronting
> "**Due to the server overload**, we experienced downtime."
> "**Because of the configuration**, the system crashed."
> "**With the new encryption**, our data is now secure."

---

## Practice Exercises

### Create cleft or fronting:

1. The security breach was due to the bug. → **It was the bug that caused the security breach.**
2. We lost data because of the error. → **Due to the error, we lost data.**
3. What we need is more training. → **Cleft sentence** (already)
4. The system failed because of the update. → **Due to the update, the system failed.**

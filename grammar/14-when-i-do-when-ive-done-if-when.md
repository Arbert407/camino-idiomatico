# When I Do and When I've Done; If and When - Grammar Guide

## "When I Do" vs "When I've Done"

### When I Do
Used for actions that will START in the future (not yet completed):

> "When I **do** the system check, I'll update you."
> "When I **start** the network analysis, I might need additional resources."

### When I've Done
Used for actions that will be COMPLETED in the future:

> "When I **have finished** the system check, I'll update you."
> "When I **have done** the analysis, I'll present the findings."

---

## Key Difference

| When I Do | When I've Done |
|-----------|-------------|
| Starting an action | Completing an action |
| "When I do the upgrade..." | "When I've done the upgrade..." |
| "When I finish..." (after) | "When I've finished..." (done) |

---

## If vs When

### If
Used for conditions that MAY or MAY NOT happen (uncertainty):

> "**If** I find a bug, I'll report it."
> "**If** the system crashes, we have a recovery plan."

### When
Used for conditions that are MORE CERTAIN to happen:

> "**When** I finish the analysis, I'll share the results."
> "**When** the system is upgraded, it will perform better."

---

## If vs When Comparison

| If | When |
|----|------|
| Possibility (may or may not) | Certainty (will happen) |
| "If it rains, I'll stay inside" | "When it rains, the ground gets wet" |
| "If we encounter errors..." | "When testing is complete..." |
| Uncertain conditions | Definite situations |

---

## Uses in IT

### When I Do / When I've Done
> "When you **do** the server maintenance, can you check the backups?"
> "When I **have done** the maintenance, I'll inspect the backups."
> "When we **start** the migration process, we need to minimize downtime."
> "When I **have finished** the migration, I'll conduct a thorough check."

### If and When
> "**If** you encounter any issues, please inform me immediately."
> "**If** there are any problems, I'll call you right away."
> "**When** the server is back up, we need to ensure everything is running."
> "**When** the testing is complete, we'll deploy the software."

## Practice Exercises

### Choose the correct option:

1. ___ I find a bug, I'll report it. → **If**

3. Call me back when you ___ done. → **have** (have done)
4. We need to wait ___ the upgrade is complete. → **until** (not when for completion)

## Common Mistakes

### ❌ Mistake: Using "when" for uncertain events
> ❌ "When the system might crash..." (if uncertain)
> ✅ "**If** the system crashes..."

### ❌ Mistake: Using wrong form for completion
> ❌ "Call me when you do the work" (when starting)
> ✅ "Call me when you've done the work" (when finished)

### ❌ Mistake: Confusing if/will and when
> "If I find a bug, I will report it" (uncertain) vs "When I find a bug, I report it" (certain)

---

## Quick Summary

| Expression | Use |
|------------|-----|
| **When I do** | Action starting in the future |
| **When I've done** | Action completed in the future |
| **If** | Possible but uncertain |
| **When** | Certain to happen |

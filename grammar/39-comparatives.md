# Comparatives: Faster Than, More Efficient Than - Grammar Guide

## Introduction

Comparatives show differences between two things.

---

## Forming Comparatives

### Short Adjectives (+ -er)

| Base | Comparative |
|------|-------------|
| fast | faster |
| cheap | cheaper |
| smart | smarter |
| old | older |

### Long Adjectives (more + adjective)

| Base | Comparative |
|------|-------------|
| efficient | more efficient |
| reliable | more reliable |
| expensive | more expensive |
| user-friendly | more user-friendly |

---

## Using Than

> "This software is **faster than** the old one."
> "The new solution is **more efficient than** the previous."

---

## As...As (Equality)

> "This model is **as reliable as** the other one."
> "The new system is **as fast as** the old one."

---

## Uses in IT

### Comparisons
> "The new server is **faster than** the old one."
> "Cloud storage is **more cost-effective** than local."
> "This software is **easier to use than** the previous version."

### Equality
> "It's **as secure as** the other option."
> "The new interface is **as intuitive as** expected."

---

## Practice Exercises

### Complete the sentences:

1. This software is ___ than the old one. (fast) → **faster**
2. The new system is ___ than ours. (efficient) → **more efficient**
3. It's ___ as the other option. (reliable) → **as reliable**
4. This solution is ___ expensive. (less) → **less expensive** or "not as expensive"
5. It's ___ easier to use. (much) → **much** easier

---

## Common Mistakes

### ❌ "more faster" (double comparative)
> ✅ "faster than" or "more efficient than"

### ❌ Missing "than"
> ❌ "This is faster the old one"
> ✅ "This is faster **than** the old one"

---

## Quick Summary

| Type | Structure | Example |
|------|-----------|---------|
| Short | adjective + er | faster |
| Long | more + adjective | more efficient |
| Equality | as + adj + as | as fast as |

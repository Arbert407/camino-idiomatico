# Conjunctions: In Case, Unless, As Long As, Provided - Grammar Guide

## Introduction

These connectors set conditions for IT actions and planning.

---

## In Case

### Use: Preparing for Possibility

> "Save your work **in case** the system crashes."
> "Backup your data **in case** there's a power outage."

### Structure

**In case + clause** (purpose)

> ✅ "Check the logs **in case** there are errors."

---

## Unless

### Use: Condition

> "The software won't work **unless** it's updated."
> "Don't proceed **unless** you get approval."

### Structure

**Unless + clause** = "if not"

> ✅ "Unless you update, the system will fail."

---

## As Long As / Provided (That)

### Use: Sufficient Condition

> "You can access the data **as long as** you have authorization."
> "You can proceed **provided (that)** you get approval."

### Structure

**As long as / Provided + clause**

> ✅ "As long as you save the file, it's secure."

---

## Summary

| Connector | Use | Example |
|-----------|-----|---------|
| **In case** | Preparation | "Save work in case of crash" |
| **Unless** | Condition | "Won't work unless updated" |
| **As long as** | Sufficient condition | "Access as long as authorized" |
| **Provided (that)** | Requirement | "Can proceed provided approved" |

---

## Uses in IT

### In Case
> "Document everything **in case** there's a dispute."
> "Check backups **in case** data is lost."

### Unless
> "The system won't start **unless** the license is valid."
> "Don't release **unless** testing passes."

### As Long As / Provided
> "You can deploy **as long as** QA approves."
> "Proceed **provided** you have documentation."

## Practice Exercises

### Complete the sentences:

1. Save your work ___ the system crashes. → **in case**
2. The app won't work ___ updated. → **unless**
3. You can access the server ___ you have permission. → **as long as**
4. You can proceed ___ you get approval. → **provided (that)**
5. Backup files ___ there's an error. → **in case**

---

## Common Mistakes

### ❌ "In case" vs "In case of"
> "In case" + clause: "In case it crashes"
> "In case of" + noun: "In case of crash"

### ❌ "Unless" meaning
> "Unless" = "if not" - NOT "if"

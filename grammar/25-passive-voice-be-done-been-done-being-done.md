# Passive Voice: be done, been done, being done - Grammar Guide

## be done (Future Passive)

### Structure

**Will be + Past Participle**

> ✅ "The system **will be upgraded** next week."
> ✅ "The security check **will be done** by Friday."

### Uses in IT
> "The maintenance **will be done** over the weekend."
> "The new software **will be installed** next Tuesday."

---

## been done (Perfect Passive)

### Structure

**Has/Have + been + Past Participle**

> ✅ "The update **has been done**."
> ✅ "All tests **have been done**."

### Uses in IT
> "The software update **has been installed**."
> "All preparations **have been done**."

---

## being done (Continuous Passive)

### Structure

**Is/are + being + Past Participle**

> ✅ "The data **is being analyzed** currently."
> ✅ "The network **is being upgraded** right now."

### Uses in IT
> "The database **is being backed up** at the moment."
> "Bug fixes **are being done** currently."

---

## Summary of All Passive Forms

| Form | Structure | Example |
|------|----------|---------|
| is done | am/is/are + done | The software is updated |
| was done | was/were + done | The server was fixed |
| will be done | will be + done | The upgrade will be done |
| has been done | has been + done | The software has been installed |
| is being done | is being + done | The data is being analyzed |

---

## Uses in IT

### Future (be done)
> "The server maintenance **will be done** over the weekend."
> "New security measures **will be done** soon."

### Completed (been done)
> "All tests **have been done**, and the software is ready."
> "The network upgrade **has been completed**."

### Ongoing (being done)
> "The data **is being processed** right now."
> "The migration **is being done** carefully."

## Practice Exercises

### Complete the sentences:

1. The upgrade ___ (do) next week. → **will be done**
2. All tests ___ (done) already. → **have been done**
3. The data ___(analyze) now. → **is being analyzed**
4. The software ___ (install) tomorrow. → **will be installed**
5. The report ___ (send) this morning. → **has been sent**

---

## Common Mistakes

### ❌ Mistake: Missing "been"
> ❌ "The software has done" (wrong)
> ✅ "The software **has been done**"

### ❌ Mistake: Wrong form
> ❌ "The data is being done analyze" (wrong)
> ✅ "The data **is being analyzed**"

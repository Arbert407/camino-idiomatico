# Passive Voice: is done, was done - Grammar Guide

## Introduction

In passive voice, the focus is on the ACTION rather than who performs it. This is common in IT for emphasizing results.

---

## is done (Present Passive)

### Structure

**Subject + am/is/are + Past Participle**

> ✅ "The software **is updated** regularly."
> ✅ "The data **is being analyzed** now."

### Uses in IT

| Example | Meaning |
|---------|---------|
| The software **is updated** regularly. | It happens routinely |
| Security protocols **are followed**. | Standard practice |
| The data **is being analyzed**. | Currently happening |

---

## was done (Past Passive)

### Structure

**Subject + was/were + Past Participle**

> ✅ "The server **was repaired** last night."
> ✅ "The system **was checked** for errors."

### Uses in IT

| Example | Meaning |
|---------|---------|
| The server **was fixed** yesterday. | Completed action |
| A new feature **was added** in the update. | Past event |
| The network analysis **was completed**. | Finished task |

---

## Active vs Passive

| Active | Passive |
|--------|---------|
| We **update** the software | The software **is updated** |
| The team **checked** the system | The system **was checked** |
| Someone **fixes** the bugs | The bugs **are fixed** |

---

## Uses in IT

### Documentation
> "Backups **are done** daily."
> "The system **was upgraded** last week."

### Reporting
> "The data **is being processed** currently."
> "The security audit **was completed** yesterday."

### Incident Reports
> "The system **was checked** immediately after the incident."
> "The issue **was resolved** by the team."

---

## Practice Exercises

### Change to passive:

1. They update the software. → The software **is updated**.
2. The team fixed the server. → The server **was fixed**.
3. We complete the tests. → The tests **are completed**.
4. Someone discovered the bug. → The bug **was discovered**.
5. They are analyzing the data. → The data **is being analyzed**.

---

## Common Mistakes

### ❌ Mistake: Using wrong tense
> ❌ "The software is was updated" (wrong)
> ✅ "The software **was updated**"

### ❌ Mistake: Adding "by" unnecessarily
> ✅ Focus on action: "The task was completed"
> ✅ Focus on agent: "The task was completed **by the team**"

---

## Quick Summary

| Tense | Form | Example |
|-------|------|---------|
| Present | is/are + done | The software is updated |
| Past | was/were + done | The server was fixed |
| Present Continuous | is/are being done | The data is being analyzed |

# Modal Verbs Could Do and Could Have Done - Grammar Guide

## Could Do

### What is it?
Used to talk about possible actions or abilities in the present or future.

> "I **could do** the system analysis tomorrow."
> "I **could do** a security check if needed."

---

## Could Have Done

### What is it?
Used to express a possible action in the past that DID NOT happen.

> "I **could have done** the network upgrade last week, but there wasn't enough time."
> "We **could have prevent** the error if we had more information."

---

## Could Do Structure

### Subject + could + base verb

| Affirmative | Negative |
|-----------|----------|
| I could do | I couldn't do |
| We could start | We couldn't start |

> ✅ "I could do it" → ❌ "I could to do it"

---

## Could Have Done Structure

### Subject + could have + past participle

| Affirmative | Negative |
|-----------|----------|
| I could have done | I couldn't have done |
| We could have started | We couldn't have started |

> ✅ "I could have finished" → ❌ "I could have finish"

---

## Uses in IT

### Could Do - Present/Future Possibilities
> "I **could do** a review of the new software patch today."
> "We **could implement** a more efficient workflow."
> "We **could do** a brainstorming session to come up with better strategies."

### Could Have Done - Past Missed Opportunities
> "We **could have done** it last week, but we were waiting for vendor confirmation."
> "We **could have started** earlier if we had received the confirmation on time."
> "We **could have done** more thorough testing to avoid these bugs."

### Speculation About Past
> "You **could have encountered** a bug in the system."
> "The server **could have crashed** due to overload."

---

## Key Differences

| Could Do | Could Have Done |
|----------|---------------|
| Present/future possibility | Past possibility not taken |
| "I could do it now" | "I could have done it" |
| "We could start tomorrow" | "We could have started" |
| Uncertain action | Missed opportunity |

## Practice Exercises

### Complete the sentences:

1. I ___ (do) a security check tomorrow. → **could do**
2. We ___ (finish) the project last week, but we didn't have time. → **could have finished**
3. We ___ (prevent) the error with more testing. → **could have prevented**
4. We ___ (consider) a different approach. → **could do** / **could consider**
5. You ___ (encounter) a bug in the system. → **could have encountered**

## Key Differences Spanish → English

| Spanish | English |
|---------|--------|
| Podría hacer esto | I **could do** this |
| Podría haber hecho esto | I **could have done** this |
| Podríamos implementar... | We **could implement**... |
| Podríamos haber hecho... | We **could have done**... |

---

## Common Mistakes

### ❌ Mistake: Using could do for past events
> ❌ "I could do it yesterday"
> ✅ "I **could have done** it yesterday"

### ❌ Mistake: Wrong form
> ❌ "I could did the work"
> ✅ "I **could do** the work"

### ❌ Mistake: Confusing with "can"
> "I can do it" (I am able) vs "I could do it" (it is possible)

---

## Quick Summary

| Form | Use | Example |
|------|-----|--------|

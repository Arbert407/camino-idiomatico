# For and Since, Have Got and Used To - Grammar Guide

## For vs Since

### "For" - Duration
Used with a period of time:

> "I have worked here **for** five years."
> "The server has been down **for** three hours."

| For + Duration | Example |
|---------------|---------|
| for + minutes, hours, days... | for 20 minutes |
| for + months, years... | for 6 months |
| for + a week/year... | for a week |

### "Since" - Starting Point
Used with a point in time:

> "I have worked here **since** 2020."
> "The server has been down **since** this morning."

| Since + Point | Example |
|--------------|---------|
| since + specific date | since January 2024 |
| since + specific time | since 3 PM |
| since + year | since 2019 |

---

## When ... ? vs How Long ... ?

### When ... ? - Specific Time
> "**When** did the meeting start?"
> "**When** did the server crash?"

### How Long ... ? - Duration
> "**How long** has the server been down?"
> "**How long** have you been working on this?"

| Question | Answer |
|----------|--------|
| When did it start? | It started at 3 PM. (specific time) |
| How long has it been running? | It's been running for hours. (duration) |

---

## Have Got vs Have

### Have Got = Have ( possession, obligations)
Used especially in British English:

> "I **have got** a new laptop." (= I have)
> "I've **got to** finish this today." (= I have to / I must)

### Have Got - Forms

| Affirmative | Negative | Question |
|-------------|----------|----------|
| I have got / I've got | I haven't got | Have I got? |

---

## Used To - Past Habits

### Used To - Past states/habits that are no longer true

> "I **used to work** in a different department."
> "I **used to use** Windows, but now I use Linux."

| Used To | Meaning |
|---------|---------|
| used to + verb | Past habit/state (no longer true |
| "I used to work late" | I worked late before, but not now |
| "I used to prefer Java" | I preferred Java before, but not now |

### Negative: Didn't Use To
> "I **didn't use to** work weekends."
> "She **didn't use to** like coding."

---

## Uses in IT Context

### For + Since in Projects
> "We have been working on this project **for** three weeks."
> "We have had these servers **since** 2022."

### When ... / How Long ... in Troubleshooting
> "**When** did the error start occurring?"
> "**How long** has this been happening?"

### Have Got in IT
> "I **have got** to complete the deployment today."
> "She **has got** the credentials."

### Used To in Career
> "I **used to work** in hardware, now I'm in software."
> "We **used to use** waterfall, now we use Agile."

## Practice Exercises

### Complete the sentences:

1. I have worked here ___ five years. → **for**
2. I have worked here ___ 2020. → **since**
3. ___ did the server crash? → **When**
4. ___ long has it been down? → **How**
5. She ___ to complete the task today. → **has got** (or "has got to")
6. I ___ work in support, now I work in development. → **used to**

## Common Mistakes

### ❌ Mistake: For + since
> ❌ "I have worked here for 2020"
> ✅ "I have worked here **since** 2020"

### ❌ Mistake: Confusing how long and when
> ❌ "When has it been down?" (wrong)
> ✅ "**How long** has it been down?"

### ❌ Mistake: Used to for current habits
> ❌ "I used to work here" (if currently working)
> ✅ "I work here" (current) or "I used to work here" (past)

### ❌ Mistake: Have got without got
> ❌ "I have to go" vs "I have got to go"
> Both are correct but have different meanings

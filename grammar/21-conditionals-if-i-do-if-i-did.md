# Conditionals: If I Do and If I Did - Grammar Guide

## Introduction

Conditionals with "if" express possibilities - real or hypothetical. In IT, we use them for planning and problem-solving.

---

## If I Do (First Conditional)

### Use: Real Possibilities in Present/Future

> "If I **do** the server check tonight, can you start the migration tomorrow?"
> "If we **upgrade** the system, it will run faster."

### Structure

**If + Present Simple → Future**

| Affirmative | Question |
|------------|----------|
| If + present, + will | If + present + ? |

> ✅ "If I **finish** early, I **will help** you."
> ✅ "If the server **crashes**, we **have** a backup plan."

---

## If I Did (Second Conditional)

### Use: Hypothetical/Unreal Situations

> "If I **did** the installation yesterday, the system would be operational now."
> "If I **used** a different method, there might be fewer bugs."

### Structure

**If + Past Simple → Would + Verb**

> ✅ "If I **knew** about the bug, I **would fix** it."
> ✅ "If we **had** more time, we **would test** more."

---

## Key Differences

| If I Do | If I Did |
|---------|----------|
| Real possibility | Hypothetical/unreal |
| "If I do this, it will work" | "If I did this, it would work" |
| Future actions | Imaginary situations |

---

## Uses in IT

### If I Do - Real Possibilities
> "If we **implement** this feature, users will be happier."
> "If I **run** the diagnostics, I can identify the issue."
> "If you **do** the server check tonight, we can migrate tomorrow."

### If I Did - Hypothetical
> "If I **started** the backup earlier, we wouldn't have lost data."
> "If we **chose** a different platform, we might avoid these issues."
> "If I **did** a thorough check, I might have spotted the error."

## Practice Exercises

### Choose the correct form:

1. If I ___ (do) the upgrade tonight, we can proceed tomorrow. → **do**
2. If I ___ (finish) earlier, I would have helped. → **finished**
3. If we ___ (use) a different approach, it might work. → **use**
4. If the system ___ (crash), we have a backup. → **crashes**
5. If I ___ (know) about the issue, I would have fixed it. → **knew**

---

## Common Mistakes

### ❌ Mistake: Using will in the if-clause
> ❌ "If it will crash, we have a backup"
> ✅ "If it **crashes**, we have a backup"

### ❌ Mistake: Using past for real situations
> ❌ "If I finished the project yesterday" (for future)
> ✅ "If I **finish** the project tomorrow"

---

## Quick Summary

| Type | If Clause | Main Clause | Example |
|------|----------|------------|---------|
| First (Real) | Present | Will | If it rains, I'll stay |
| Second (Unreal) | Past | Would | If it rained, I'd stay |

# Understanding Phrasal Verbs in IT - Grammar Guide

## Introduction

Phrasal verbs combine verbs with prepositions/adverbs. In IT, they're essential for technical communication.

---

## Common IT Phrasal Verbs

| Phrasal Verb | Meaning | IT Example |
|-------------|---------|------------|
| **log in** | access system | "Log in to the server." |
| **log out** | leave system | "Log out when finished." |
| **back up** | create copy | "Back up the data." |
| **shut down** | turn off | "Shut down the system." |
| **set up** | prepare | "Set up the network." |
| **run through** | review | "Run through the process." |

---

## Separable vs Inseparable

### Separable (Verb + Object can be separated)

| Form | Example |
|------|---------|
| verb + noun | "Back up the data." |
| verb + pronoun | "Back it up." |

### Inseparable (Cannot separate)

> "Log in to the system." (NOT "Log to the system in.")

---

## Uses in IT

### Log In/Out
> "Did you **log in** to the database?"
> "Remember to **log out** after your session."

### Back Up
> "We need to **back up** all client data."
> "**Back up** the files before updating."

### Set Up / Shut Down
> "We need to **set up** a meeting."
> "Don't forget to **shut down** the server."

## Practice Exercises

### Complete the sentences:

1. Remember to ___ in to the system. → **log**
2. We need to ___ up the data before the update. → **back**
3. Please ___ down the server for maintenance. → **shut**
4. Let's ___ up a meeting to discuss the project. → **set**
5. I'll run ___ the migration process. → **through**

---

## Common Mistakes

### ❌ "Log in the system" (wrong)
> ✅ "Log **in to** the system"

### ❌ Separating inseparable
> ✅ "Back it up" (separable with pronoun)
> ✅ "Back up the data" (separable with noun)

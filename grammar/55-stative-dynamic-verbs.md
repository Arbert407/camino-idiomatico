# Stative and Dynamic Verbs in IT - Grammar Guide

## Introduction

Stative verbs describe states; dynamic verbs describe actions.

---

## Stative Verbs (States)

| Verb | Meaning | IT Example |
|------|---------|------------|
| **know** | knowledge | "I **know** the solution." |
| **understand** | comprehension | "She **understands** the code." |
| **need** | requirement | "We **need** a faster server." |
| **prefer** | choice | "I **prefer** Python." |
| **own** | possession | "We **own** the license." |
| **believe** | opinion | "I **believe** this works." |
| **belong** | belonging | "This server **belongs** to us." |
| **seem** | appearance | "It **seems** to work." |

---

## Dynamic Verbs (Actions)

| Verb | Action | IT Example |
|------|--------|------------|
| **write** | create | "I **write** code." |
| **code** | program | "She **codes** in Java." |
| **install** | setup | "We **install** software." |
| **repair** | fix | "They **repair** servers." |
| **develop** | create | "We **develop** apps." |
| **test** | check | "I **test** the system." |
| **run** | execute | "The system **runs** smoothly." |

---

## Key Differences

| Stative | Dynamic |
|---------|---------|
| States, thoughts, emotions | Actions, processes |
| Usually not continuous | Can be continuous |
| "I understand" | "I'm working" |

---

## Uses in IT

### Stative Verbs
> "I **understand** the algorithm."
> "We **need** more bandwidth."
> "This software **belongs** to our company."

### Dynamic Verbs
> "I'm **coding** the application."
> "We're **testing** the system."
> "The server is **running** smoothly."

---

## Practice Exercises

### Identify stative (S) or dynamic (D):

1. I understand the code. → **S**
2. I'm installing the software. → **D**
3. We need more RAM. → **S**
4. She writes code daily. → **D**
5. The system seems fast. → **S**

---

## Quick Summary

| Type | Examples | Continuous |
|------|----------|------------|
| **Stative** | know, need, prefer | No |
| **Dynamic** | write, code, test | Yes |

# English Grammar Essentials - Quick Reference Guide

---

## 1. SUBJECT

**Definition**: The person or thing that performs the action or is being described in a sentence.

### Examples in IT Context:
> "The **server** crashes." (server = subject)
> "**I** write code every day." (I = subject)
> "**Python** is a popular language." (Python = subject)

### Types of Subjects:

| Type | Example |
|-----|---------|
| **Simple** | "She codes." |
| **Compound** | "**Mike and I** work together." |
| **Dummy** | "**It** is raining." |

---

## 2. VERB

**Definition**: The action or state of being in a sentence.

### Types of Verbs:

#### a) Action Verbs (Dynamic)
> "She **builds** APIs."
> "He **debugs** the code."

#### b) State Verbs (Stative)
> "I **know** the answer."
> "She **owns** a laptop."

#### c) Helping Verbs (Auxiliary)
> "I **am** working." (am = helping)
> "She **has** finished." (has = helping)

### Verb Forms:

| Form | Example |
|------|--------|
| Base | work |
| Present (-s) | works |
| Past | worked |
| Participle | worked / working |

---

## 3. NOUN

**Definition**: A word that names a person, place, thing, or concept.

### Types of Nouns:

#### a) Common Nouns (general)
> "**developer**", "**server**", "**code**"

#### b) Proper Nouns (specific names)
> "**Java**", "**Google**", "**Linux**"

#### c) Countable Nouns
> "**one** laptop", "**two** servers"

#### d) Uncountable Nouns
> "**water**", "**information**", "**software**"

#### e) Collective Nouns
> "**team**", "**group**", "**staff**"

#### f) Compound Nouns
> "**software engineer**", "**user interface**"

### Nouns in IT:
> "**API**", "**database**", "**bug**", "**feature**", "**deployment**"

---

## 4. ADJECTIVE

**Definition**: A word that describes or modifies a noun.

### Position:

1. **Before noun**: "a **fast** server"
2. **After verb**: "The server is **fast**"

### Types:

#### a) Descriptive
> "The code is **clean**."

#### b) Demonstrative
> "**this** laptop", "**that** error"

#### c) Possessive
> "**my** computer", "**her** password"

#### d) Quantitative
> "**three** servers", "**many** bugs"

### Comparison:

| Form | Use | Example |
|------|-----|---------|
| Base | 1 item | "fast server" |
| -er / more | 2 items | "faster than..." |
| -est / most | 3+ items | "the fastest..." |

> "This server is **faster** than that one."
> "JavaScript is **more popular** than Ruby."

---

## 5. ADVERB

**Definition**: A word that modifies a verb, adjective, or another adverb.

### Common Endings: **-ly**

### Types:

#### a) Manner (how)
> "She speaks **clearly**."
> "He codes **carefully**."

#### b) Time (when)
> "I work **daily**."
> "She checks logs **weekly**."

#### c) Place (where)
> "The data is stored **here**."
> "Look **there**."

#### d) Frequency (how often)
> "I **always** test my code."
> "The server **never** crashes."

### Adverbs in IT:
> "Please install the package **correctly**."
> "The system runs **efficiently**."

---

## 6. MODAL VERBS

**Definition**: Auxiliary verbs that express ability, possibility, permission, or obligation.

### The Main Modal Verbs:

| Modal | Meaning | Example |
|------|---------|---------|
| **can** | Ability / Permission | "I **can** code in Python." |
| **could** | Past ability / Polite request | "**Could** you help me?" |
| **may** | Possibility / Permission | "It **may** fail." |
| **might** | Weak possibility | "It **might** work." |
| **must** | Strong obligation | "You **must** backup data." |
| **have to** | Obligation | "I **have to** fix this bug." |
| **should** | Advice | "You **should** test it." |
| **would** | Conditional / Polite | "**Would** you like to help?" |
| **will** | Future / Willingness | "I **will** deploy it." |

### Modal + Base Verb (no -s, no to):

> ❌ "She can **works** hard"
> ✅ "She **can work** hard."

> ❌ "He should to **help**"
> ✅ "He **should help**"

### Short Answers with Modals:

| Question | Yes | No |
|----------|-----|---|
| Can you help? | Yes, I **can** | No, I **can't** |
| Should I fix it? | Yes, you **should** | No, you **shouldn't** |

---

## 7. PHRASAL VERBS

**Definition**: A verb + particle (preposition/adverb) that together has a new meaning.

### Types:

#### a) Separable
(verb and particle can be separated)
> "Turn **the server** on." = "Turn **on** the server."

#### b) Inseparable
(cannot be separated)
> "Look **after** the system." (NOT: Look the system after)

### Common IT Phrasal Verbs:

| Phrasal Verb | Meaning |
|--------------|---------|
| **back up** | Create a backup |
| **break down** | Analyze into parts |
| **bring up** | Start or launch |
| **carry out** | Execute |
| **check in** | Submit code |
| **check out** | Retrieve or sign out |
| **come across** | Find by accident |
| **figure out** | Understand or solve |
| **find out** | Discover |
| **get across** | Communicate |
| **get rid of** | Remove |
| **give up** | Quit or stop |
| **go through** | Review or experience |
| **hand in** | Submit |
| **look for** | Search |
| **look up** | Search for information |
| **pick up** | Learn quickly |
| **set up** | Configure or install |
| **take off** | Remove or depart |
| **test out** | Test |
| **turn down** | Reject |
| **turn up** | Appear or increase |
| **work out** | Solve or function |

### Examples:
> "We need to **back up** the database." (separate)
> "I **came across** an interesting bug." (inseparable)
> "Can you **figure out** the error?" (separate)

---

## 8. PREPOSITION

**Definition**: A word that shows the relationship between a noun/pronoun and another word.

### Common Prepositions:

| Preposition | Meaning | Example |
|--------------|---------|---------|
| **in** | Inside | "in the server" |
| **on** | Surface | "on the screen" |
| **at** | Point | "at 3pm" |
| **to** | Direction | "go to the office" |
| **from** | Origin | "email from client" |
| **of** | Belonging | "the name of the file" |
| **for** | Purpose | "code for the app" |
| **with** | Accompaniment | "with the team" |
| **without** | Lack | "without errors" |
| **about** | Topic | "about the bug" |
| **through** | Via | "through the API" |
| **into** | Inside | "log into the system" |
| **onto** | Surface of | "upload onto the server" |
| **over** | Above | "over the network" |
| **under** | Below | "under the table" |

### Prepositional Verbs (fixed combinations):

> "wait **for**" (NOT: wait to)
> "search **for**"
> "look **at**"
> "depend **on**"

### Preposition at End:

In questions, the preposition often comes at the end:
> "What are you looking **at**?"
> "Who are you waiting **for**?"

---

## 9. CONJUNCTION

**Definition**: A word that connects words, phrases, or clauses.

### Types:

#### a) Coordinating (FANBOYS)
> **F**or **A**nd **N**or **B**ut **O**r **Y**et **S**o

> "I code **and** she designs."
> "You can use Git **or** Subversion."
> "He tests **but** doesn't document."

#### b) Subordinating
> "**Because** it crashed, we lost data."
> "**Although** it's old, it works."
> "**If** you fix it, it will work."

#### c) Correlative
> "**Both** you **and** I are developers."
> "**Either** you **or** the team will fix it."

---

## 10. PRONOUN

**Definition**: A word that replaces a noun.

### Types:

| Type | Examples |
|------|-----------|
| **Personal** | I, you, he, she, it, we, they |
| **Possessive** | my, your, his, her, its, our, their |
| **Reflexive** | myself, yourself, himself, herself, ourselves, themselves |
| **Demonstrative** | this, that, these, those |
| **Indefinite** | anyone, someone, everyone, nobody |
| **Relative** | who, which, that |
| **Interrogative** | who, what, which, whose |

### Examples in IT:
> "**Who** wrote this code?"
> "**This** is better than **that**."
> "**Everyone** should test their code."

---

## 11. DETERMINER

**Definition**: Words that come before nouns to indicate which specific or general noun is being referred to.

### Types:

#### a) Articles
> **a/an** (indefinite): "a server" / "an error"
> **the** (definite): "the database"

#### b) Demonstratives
> "**This** server is fast."
> "**Those** errors are critical."

#### c) Quantifiers
> "**many** bugs", "**few** issues", "**most** developers"

#### d) Possessives
> "**my** code", "**their** project"

---

## 12. CLAUSE

**Definition**: A group of words that contains a subject and a verb.

### Types:

#### a) Independent Clause
(Can stand alone - complete sentence)
> "I write code."

#### b) Dependent Clause
(Cannot stand alone - needs main clause)
> "**When** I finish work..." (dependent)
> "I finish work **when** I test everything." (independent + dependent)

---

## 13. PHRASE

**Definition**: A group of words without a subject and verb.

### Types:

| Type | Example |
|------|---------|
| **Noun** | "writing code" |
| **Adjective** | "very fast" |
| **Prepositional** | "in the cloud" |

## Common Grammar Mistakes in IT English

### 1. Subject-Verb Agreement

> ❌ "The data **are** corrupted"
> ✅ "The data **is** corrupted" (data = uncountable)

### 2. Using -s incorrectly

> ❌ "He **needs** to work"
> ✅ "He **need** to work" → Wait, this IS correct with "need" as a main verb!

> ❌ "He **can** to work"
> ✅ "He **can work**" (modal + base verb)

### 3. Preposition Errors

> ❌ "depend **on**"
> ✅ (This is correct!)

> ❌ "based **in** the cloud"
> ✅ "based **on** the cloud"

### 4. Word Order

> ❌ "Never I have seen this"
> ✅ "I **have never** seen this"

### 5. Articles with Uncountable Nouns

> ❌ "an information"
> ✅ "a piece of information" or "information" (no article)

## 14. OBJECT

**Definition**: The person or thing that receives the action of the verb.

### Types:

#### a) Direct Object (receives the action directly)
> "She writes **code**." (code = direct object)
> "He fixed **the bug**."

#### b) Indirect Object (receives what the direct object refers to)
> "She gave **me** a task." (me = indirect)
> "Send **them** the email."

#### c) Object of Preposition
> "Work **with the team**."
> "Code **in Python**."

### Position of Objects:
> "I read **the documentation**." (object after verb)
> "I read it **every day**." (object + adverb)

---

## 15. COMPLEMENT

**Definition**: A word or phrase that is needed to complete the meaning of a sentence.

### Types:

#### a) Subject Complement
> "She is **a developer**." (describes the subject)
> "He became **tired**."

#### b) Object Complement
> "They named him **leader**."
> "We consider the code **perfect**."

#### c) adverbial Complement
> "She works **from home**."

---

## 16. ASPECT

**Definition**: Shows whether an action is ongoing, completed, or habitual.

### Types:

#### a) Simple Aspect (complete action)
> "I deployed the app."

#### b) Continuous/Progressive Aspect (ongoing action)
> "I am deploying the app."
> "The server is running."

#### c) Perfect Aspect (completed action with relevance to now)
> "I have deployed the app."
> "She has finished testing."

#### d) Perfect Continuous (ongoing completed action)
> "I have been working for 3 hours."

---

## 17. TENSE

**Definition**: Shows when an action happens (past, present, or future).

### Overview:

| Tense | Example | Use |
|------|---------|-----|
| **Present Simple** | "I work" | Habits, facts |
| **Present Continuous** | "I am working" | Happening now |
| **Present Perfect** | "I have worked" | Past + now |
| **Present Perfect Continuous** | "I have been working" | Ongoing + finished |
| **Past Simple** | "I worked" | Completed past |
| **Past Continuous** | "I was working" | Past ongoing |
| **Past Perfect** | "I had worked" | Past before past |
| **Future Simple** | "I will work" | Future |
| **Future Continuous** | "I will be working" | Future ongoing |

---

## 18. VOICE

**Definition**: Shows whether the subject does or receives the action.

### Types:

#### a) Active Voice (subject does the action)
> "**The developer** wrote the code."
> "**She** fixed the bug."

#### b) Passive Voice (subject receives the action)
> "**The code** was written (by the developer)."
> "**The bug** was fixed."

### Passive Form:
**be + past participle**

| Active | Passive |
|--------|---------|
| writes | is written |
| wrote | was written |
| will write | will be written |
| has written | has been written |

### Passive with "by":
> "The app was created **by** the team."

### Passive with agents:
> "The server is managed **by** Kubernetes."

---

## 19. GERUND

**Definition**: The **-ing** form of a verb used as a noun.

### As Subject:
> "**Coding** is my passion."
> "**Testing** is important."

### As Object:
> "I enjoy **programming**."
> "She started **learning** Python."

### After Prepositions:
> "I am good **at coding**."
> "She is interested **in testing**."

### Gerund vs Infinitive:

| Gerund (+ doing) | Infinitive (+ to do) |
|----------------|--------------------|
| I like **coding** | I like **to code** |
| I stopped **working** | I stopped **to work** |

---

## 20. INFINITIVE

**Definition**: The base form of a verb, usually with "to".

### Uses:

#### a) To express purpose
> "I study **to learn** English."
> "She works **to earn** money."

#### b) After adjectives
> "It is easy **to understand**."
> "This is hard **to fix**."

#### c) After verbs
> "I want **to work**."
> "She decided **to leave**."

### Bare Infinitive (without "to") after modals:
> "I **can** help you."
> "Let him **do** it."

---

## 21. PARTICIPLE

**Definition**: A verb form that can be used as an adjective or part of a tense.

### Types:

#### a) Present Participle (-ing)
> "The **working** server is fast."
> "I saw a **running** process."

#### b) Past Participle (-ed or irregular)
> "The **deployed** app works well."
> "The **broken** code needs fixing."

### Participle as Adjective:
> "This is an **interesting** problem."
> "The **attached** file."

### Perfect Participle (having + past participle):
> "**Having completed** testing, we deployed."

---

## 22. ARTICLE

**Definition**: A type of determiner that introduces a noun.

### Types:

#### a) Indefinite Articles: a / an
> "a server" (consonant sound)
> "an API" (vowel sound)
> "anError" (silent h)

#### b) Definite Article: the
> "the database"
> "the specific server"

### No Article:
> "I work in **tech industry**." (general)
> "She is **CEO**." (title)

### Article with Common IT Terms:
> "I use **an** API."
> "**The** Internet is slow."
> "**A** bug was found."

---

## 23. INTERJECTION

**Definition**: A word or phrase that expresses emotion.

### Common Interjections:

| Interjection | Meaning |
|--------------|---------|
| **Wow!** | Surprise |
| **Oops!** | Mistake |
| **Hey!** | Attention |
| **Okay / OK** | Agreement |
| **Great!** | Positive |
| **Hmm** | Thinking |
| **Ah!** | Realization |
| **Oh no!** | Negative |

### In IT Context:
> "Wow! The code works!"
> "Oops! I deleted the database!"
> "Great! The deployment succeeded!"

**Definition**: Shows whether a noun is singular or plural.

### Singular:
> "one server"
> "one bug"

### Plural:
> "three servers"
> "many bugs"

### Irregular Plurals:

| Singular | Plural |
|----------|--------|
| server | servers |
| bug | bugs (regular) |
| index | indices / indexes |
| codebases | codebases |
| viruses | viruses |
| analysis | analyses |
| hypothesis | hypotheses |

### Countable vs Uncountable:

| Countable | Uncountable |
|----------|-------------|
| two servers | much memory |
| a few errors | some information |
| many users | no software |

## 25. GENDER (in Pronouns)

**Definition**: Shows whether a noun is masculine, feminine, or neutral.

### In English (pronouns):

| Gender | Pronouns |
|--------|----------|
| **Masculine** | he, him, his |
| **Feminine** | she, her, hers |
| **Neutral** | it, its |
| **Mixed** | they, them, their |

### For People:
> "The developer - **he** / **she**"
> "The teamleader - **he** or **she**"

### For Things:
> "The server - **it**"
> "The API - **it**"

### Indefinite (no gender):
> "Anyone can learn."
> "Someone is calling."

## 26. CASE

**Definition**: Shows the function of a noun or pronoun in a sentence.

### Types:

#### a) Nominative (Subject)
> "**She** codes." (subject)

#### b) Accusative (Object)
> "I called **her**." (direct object)

#### c) Dative (Indirect Object)
> "I gave **her** access." (to + her)

#### d) Possessive
> "**her** code"

### Case in Pronouns:

| Subject | Object | Possessive |
|---------|---------|------------|
| I | me | my / mine |
| you | you | your / yours |
| he | him | his |
| she | her | her / hers |
| it | it | its |
| we | us | our / ours |
| they | them | their / theirs |

---

## 27. MOOD

**Definition**: Shows the attitude of the speaker toward the action.

### Types:

#### a) Indicative (Statement/Fact)
> "The server works."
> "I am a developer."

#### b) Imperative (Command)
> "Run the test!"
> "Fix the bug now!"

#### c) Subjunctive (Hypothetical/Wish)
> "I wish I **were** faster."
> "If I **were** you, I would backup."
> "It's important that he **be** present."

### Subjunctive in IT:
> "I suggest that he **review** the code."
> "It is critical that the system **be** secure."

---

## 28. WORD ORDER

**Definition**: The typical order of words in an English sentence.

### Basic SVO (Subject-Verb-Object):
> "She (S) writes (V) code (O)."

### Standard English Order:

| Position | Example |
|----------|---------|
| 1. Subject | "I" |
| 2. Verb | "write" |
| 3. Object | "code" |
| 4. Adverb (manner) | "carefully" |
| 5. Place | "in the cloud" |
| 6. Time | "every day" |

### Question Word Order:
> "Where (Q) do (V) you (S) work (V)?" (wh-question)

### Negative Order:
> "I do not (don't) understand."

### Common Mistakes:

| Wrong | Correct |
|-------|----------|
| "Yesterday went I to work." | "I went to work yesterday." |
| "Very well he codes." | "He codes very well." |
| "To code, I want to learn." | "I want to learn to code." |
